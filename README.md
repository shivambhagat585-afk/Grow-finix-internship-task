# Growfinix Internship - Task 1: Automated Web Scraper

## Project Overview
This Python script scrapes public real estate/property listings, extracts property titles, prices, and locations, cleans the data, and exports it into a structured CSV file.

## Tech Stack
* Python 3
* Requests
* BeautifulSoup4
* CSV / Pandas

## Setup and Run
1. Clone repository:
   git clone https://github.com/your-username/your-repo-name.git
2. Install dependencies:
   pip install requests bs4
3. Run scraper:
   python scraper.py
